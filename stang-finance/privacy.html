Privacy Policy

Stang Finance · Effective November 22, 2026

Stang Finance ("the app") is a personal macOS application built and used by Kyle Steiner to maintain his own household budget spreadsheets. This policy explains what data the app accesses, how it uses that data, and how the data is stored and protected.

1. Data the app accesses

  • Google user data: when the app is authorized, it uses the Google Sheets API (scope https://www.googleapis.com/auth/spreadsheets) to read and update the contents of the owner's budget spreadsheets: cell values and tab names in those specific sheets. It doesn't access Gmail, Google Drive files other than those spreadsheets, contacts, calendar, or any other Google data.
  • Financial account data: transactions and balances from the owner's own bank and card accounts, retrieved through Plaid with the owner's permission.
  • Order details: item names and totals from the owner's own Amazon order history, read in the owner's browser to help categorize purchases.

2. How the data is used

The data is used only to categorize the owner's transactions, show them to the owner for review, and, after the owner approves, write the approved rows and balances to the owner's own spreadsheets. To suggest categories, transaction descriptions and amounts are sent to Anthropic's Claude API under the owner's own API account. Data isn't used for advertising, profiling, or any purpose other than the app's budgeting function.

3. Storage and security

  • Data is stored only on the owner's own Mac and in the owner's own Google spreadsheets. There is no app server or third-party database.
  • Credentials and access tokens are kept in the macOS Keychain or in owner-only files on that Mac.
  • All network connections to Google, Plaid and Anthropic use HTTPS.

4. Sharing

The app doesn't sell, rent, or share Google user data or any other personal data with anyone. Data is transferred only to the services described above (Google Sheets, Plaid and Anthropic) as needed to perform the app's function for the owner.

5. Google API Services User Data Policy

Stang Finance's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

6. Retention and deletion

Local data is kept on the owner's Mac until the owner deletes it. Access to Google can be revoked at any time from Google Account › Security › Third-party access. Removing the app and its data folder deletes all locally stored data.

7. Changes

If this policy changes, the updated version will be posted on this page with a new effective date.
